## 一页结论

v2 在 v1 基线上做了两件事，**分开报告，互不混淆**：

**阶段 A — 只修程序与统计，控制参数一字未改。**
关阀事件改为单调锁存，从构造上保证只关一次；诊断改为分段时间加权、开闭阀分别积分、
斜率分别判定、水量平衡区分构造恒等式与真检查。
结论层面唯一被纠正的是：**平台最差偏差 +0.96% → +2.38%**，
因为 v1 的平台窗口从 `rise_s + 0.2 s` 起算，把升流交班处的过冲峰排除在外了。
关阀时刻、峰值接触力、峰值步频在 v1/v2 完全相同——关阀抖动是潜在缺陷，在 v1 里恰好没有咬到结果。

**阶段 B — 同一控制器接完整五状态参考模型，不重新调参。**
MATLAB 端从冻结的 Python 源码逐行移植，在 4800 个状态点上逐点验证
（右端项最差相对差 4.3×10⁻¹⁹，雅可比 3.3×10⁻¹⁶）。五个工况全部完成，无守卫违规。
但完整模型给出了 ROM 看不见的两条：

> - **峰值转矩用掉假设转矩包络的 98.0%**（闭环三档，出现在 2 s 启动升流末端），
>   相位裕度 11.4°。**15 mL/s 是 near-limit design case，本包不判定它可行。**
> - **固定步频的转矩峰值出现在关阀之后**（t=25.95 s vs 关阀 25.64 s），
>   占包络 96.3%，此时已经不再出水。

**阶段 C（终止策略优化）未在本包内执行。**

### 必须与数字一起讲的边界

1. **末端体积误差 ≈ 0 是记账自洽，不是控制精度。** 阀在理想体积事件上关闭，
   交付尾水恰好等于补偿掉的尾水。真实尾水若为 1.0/1.5/2.5/3.0 mL，误差就是 −1.0/−0.5/+0.5/+1.0 mL。
2. **转矩包络本身是条件性平坦假设**，不是实测 12 V 运行转矩曲线；0.67 A 是估计电流。
   98% 这个数字既是对控制器的警告，也是对这条假设的警告。
3. 非电机等效质量 0.5 kg、阻尼 20 N·s/m、摩擦 0.1 N、接触刚度 2×10⁵ N/m **全是假设**，未辨识。
4. 反馈仍是理想无噪的，无量程、无量化、无噪声、无延迟。
5. 尾水 2 mL 与约 1.33 s 是用户提供的信息；**半余弦形状与 T=2V/q0 规则仍是模型假设**。
   固定步频关阀时 q0≈8.66 mL/s 给出 T=0.462 s，那是外推，不是实测时间。
6. 模型系数、稀疏结构、Rh 全部沿用冻结值。**没有重新辨识，没有新增基函数，
   没有为了改善曲线动过流阻。**
